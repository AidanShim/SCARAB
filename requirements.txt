# SCARAB dependencies.
#
# One environment runs the ENTIRE main_project pipeline (preprocessing +
# clustering + training) -- the split across the legacy `ubopendata` (py3.7 /
# TF 1.14) and `scarab` envs is no longer needed. `ubopendata` is only still
# required for tutorial/MBOONE/microboone_open_data.ipynb, which imports pynuml
# (see the OPTIONAL section at the bottom); main_project/MBOONE/plane_2.py
# deliberately reads wire_table with plain h5py instead, so nothing in the main
# pipeline needs pynuml.
#
#   python -m venv .venv && .venv/bin/pip install -r requirements.txt
#   # or: conda create -n scarab python=3.11 && pip install -r requirements.txt
#
# Python 3.11 recommended (3.9+ works). Verified working set, 2026-08-05:
#   python 3.11.15  tensorflow 2.21.0  keras 3.15.0  numpy 2.0.1  h5py 3.14.0
#   scipy 1.16.0  scikit-image 0.26.0  scikit-learn 1.9.0  matplotlib 3.11.0
#   pandas 3.0.3  torch 2.5.1  torchvision 0.20.1
# To freeze this exactly for a cluster run:  pip freeze > requirements-lock.txt
